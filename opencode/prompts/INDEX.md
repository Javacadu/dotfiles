# Raw Prompt Library

Base directory for this index and all relative file references below: `~/.config/opencode/prompts/`.

Verbatim copies of extracted system prompts, deduplicated to the strongest example per use case. Skills and agents reference these files for full-fidelity context on demand. Read the matching file when a task needs the complete original guidance, not just the distilled rules.
